# Candidature

Ce dépôt contient les documents de candidature de Martin Muller (CV en HTML,
lettres, textes de présentation).

## Règle d'écriture

Tout texte rédigé ici passe par la compétence `humanizer`
(`.claude/skills/humanizer/SKILL.md`) avant d'être livré : CV, lettre de
motivation, résumé de profil, message d'accompagnement, description
d'expérience. La compétence s'applique aussi aux réécritures partielles, pas
seulement aux textes créés de zéro.

Ce qui reste inchangé : le code HTML et CSS, les dates, les intitulés de poste,
les noms d'entreprise, les diplômes et les chiffres. La compétence corrige la
prose, pas les faits.

Règle absolue pour une candidature : ne jamais inventer une expérience, une
certification, une date, un employeur ou un chiffre. Si une phrase manque
d'information, poser la question plutôt que de combler le vide.

## Adaptation au français

Les mots surveillés de la compétence sont en anglais. Les équivalents français
qui reviennent le plus dans les CV générés :

- « fort de », « riche de », « au cœur de », « véritable atout », « passionné par »
- « alliant rigueur et », « garant de la sécurité », « acteur clé »
- « permettant de », « assurant », « contribuant à », « favorisant » en fin de phrase
- « dynamique », « polyvalent », « proactif », « à l'écoute » sans exemple derrière
- « qui ne demande qu'à », « prêt à relever de nouveaux défis »

Les règles §14 (tirets cadratins), §17 (majuscules dans les titres), §18
(emojis) et §19 (guillemets courbes) s'appliquent telles quelles, en gardant les
guillemets français « » quand le document les utilise déjà.
